# What does thermodynamic structure buy a learned model of an adsorption column?

[![verify](https://github.com/abdulhamidbatayhi123/ai-column-structure/actions/workflows/verify.yml/badge.svg)](https://github.com/abdulhamidbatayhi123/ai-column-structure/actions/workflows/verify.yml)

Paper 3B of a research program on AI for water sorption in metal-organic frameworks (MOFs).
This repository holds the complete, open design of a pre-registered computational study.

**The question.** A learned reduced model of a non-isothermal adsorption column, such as a MOF
water-harvesting bed, can be built so that it balances water and energy exactly against its
inlet, outlet and wall, and never destroys entropy in total. Its energy and entropy are taken
from the adsorbent's and the gas's thermodynamics, not learned. Does that structure buy what
it is supposed to buy, stable long multi-cycle rollouts and data efficiency? What does it cost
in accuracy against the same model without structure? And if it helps, is it the structure,
or only the extra physical information the structured model sees?

The study is designed so that a negative answer is as publishable as a positive one. Every
hypothesis, metric, threshold and verdict word is fixed in advance.

## The design in five points

1. **The model.** The column is a port-metriplectic system with an empty Poisson part. Its
   friction operator holds dispersion, conduction and linear-driving-force uptake, and
   convection and wall heat are ports. Every dissipative mechanism has a proof of
   non-negative entropy production
   ([formulation](docs/formulation_3B.md), Sections 3 and 4).
2. **Paper 1 is an exact limit.** With the water's heat capacity set to zero, the reference
   model reproduces Paper 1's verified solver to better than 10⁻⁸ (verification V1). The
   reference model adds the adsorbed water's heat capacity, which Paper 1 omits. At
   saturation it holds 27 to 101 % as much heat capacity as the solid.
3. **The latent model keeps the physical guarantees.** Energy and entropy are evaluated on the
   decoded fields, so the exact balances and the non-negative total entropy production are
   statements about physical quantities, not learned ones
   ([formulation](docs/formulation_3B.md), Section 5).
4. **Strong controls.** The structured model is compared against:
   - the same model without structure;
   - that model given the same physical features (U+F);
   - that model with the same balance projection applied at rollout (U+proj);
   - a compute-matched version;
   - a physics-penalty version;
   - two ablations;
   - a Fourier neural operator, Paper 1's strongest field model (descriptive);
   - a coarse thermodynamically consistent solver that needs no learning at all.

   Every primary hypothesis is replicated on a second material (Al-fumarate-like).

   ([pre-registration](PREREG_P3B_draft.md), Section 3.)
5. **Pre-declared verdicts.** A 14-row ordered decision list maps every combination of
   outcomes to one headline. It was checked by brute force over all 64 combinations
   ([pre-registration](PREREG_P3B_draft.md), Section 5).

## Reproduce the verification

The verification code imports three files from Paper 1's public release, unchanged
(`isotherm.py`, `solver_fd.py`, `gen_parametric_dataset.py` at tag
[v2.0.1](https://github.com/abdulhamidbatayhi123/ai-mof-cof-dynamics/tree/v2.0.1)). Place the
two repositories side by side:

```bash
git clone https://github.com/abdulhamidbatayhi123/ai-column-structure.git
git clone --branch v2.0.1 --depth 1 https://github.com/abdulhamidbatayhi123/ai-mof-cof-dynamics.git
cd ai-column-structure
pip install -r requirements.txt
python verify/run_checks.py            # writes verify/results_run_checks.json (minutes, one core)
python verify/check_results.py --bindings
python -m pytest -q tests
```

`check_results.py` applies the pass criteria of every claim the formulation makes. It also
checks that every number the formulation quotes from the results file still matches it. CI
runs all of this on every push.

| check | what it tests | result (`verify/results_run_checks.json`) |
|---|---|---|
| V1 | the water-heat-capacity-zero limit against Paper 1's solver | below 2×10⁻⁹ in c, below 10⁻⁸ in q, below 2×10⁻⁷ K in T (solver tolerance) |
| V2 | water, energy and entropy identities and the sign of every production term over two temperature-swing cycles | identities below 10⁻¹⁴ (round-off); every production term ≥ 0 to round-off |
| V3 | concavity of the gas-stream and cell entropies at 200 random states | negative semidefinite |
| V4 | whether coarse-grained data keep the balances and the entropy inequality | yes, with the fine outlet stored; the coarse outlet cell is off by 4.0 % |
